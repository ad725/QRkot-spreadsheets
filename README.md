# Благотворительный фонд поддержки котиков QRKot

Вымышленный благотворительный фонд поддержки котиков QRKot собирает пожертвования на всевозможные задачи, связанные с помощью кошачьей популяции: на корм, на медицинское обслуживание, организацию приютов и на другую помощь котам, кошкам и котятам. Приложение позволяет создавать целевые проекты для сбора средств и принимать пожертвования от пользователей.

### Данный проект позволяет:
- создавать и управлять целевыми проектами
- принимать пожертвования от пользователей
- автоматически распределять поступающие пожертвования по целевым проектам
- получать информацию о всех целевых проектах и обо всех пожертвованиях
- регистрировать и аутентифицировать пользователей с помощью JWT-токенов
- разграничивать права доступа между анонимными, зарегистрированными пользователями и суперпользователями
- генерировать Excel-отчёт по закрытым проектам с сортировкой по скорости сбора
- автоматически загружать отчёт на Яндекс Диск и получать публичную ссылку на отчет

### Как запустить проект QRKot:

Клонировать репозиторий и перейти в него в командной строке:
```bash
git clone https://github.com/ad725/cat-charity-2
cd cat-charity-2
```

Cоздать и активировать виртуальное окружение:
```bash
python3 -m venv venv
```
* Если у вас Linux/macOS
    ```bash
    source venv/bin/activate
    ```
* Если у вас Windows
    ```bash
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:
```bash
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```
Применить миграции Alembic:
```bash
alembic upgrade head
```
Создайте файл .env в корне проекта:
```bash
nano .env
```
Пример содержимого:
```bash
APP_TITLE=Благотворительный фонд QRKot
APP_AUTHOR=ad725
AUTHOR_PASS=qwerty123
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
SECRET=qwerty
FIRST_SUPERUSER_EMAIL=root@admin.ru
FIRST_SUPERUSER_PASSWORD=root
YANDEX_DISK_TOKEN=secret_yandex_token
```

Запустить сервер:
```bash
uvicorn app.main:app --reload
```

### Описание переменных окружения файла .env:
- APP_TITLE - Название приложения (отображается в документации API)
- APP_AUTHOR - Имя автора проекта (идентифицирует автора или владельца проекта)
- AUTHOR_PASS -	Секретный пароль для аутентификации автора проекта при выполнении административных действий
- DATABASE_URL -  Определяет параметры подключения к базе данных, включая тип СУБД, драйвер, учетные данные и имя базы
- SECRET - Секретная строка, используемая для генерации и валидации JWT-токенов
- FIRST_SUPERUSER_EMAIL - Email первого суперпользователя (администратора)
- FIRST_SUPERUSER_PASSWORD - Пароль первого суперпользователя (администратора)
- YANDEX_DISK_TOKEN - OAuth токен для записи отчета на Яндекс диск (получать по адресу [https://oauth.yandex.ru/](https://oauth.yandex.ru/))

### Примеры работы с API:

### Регистрация нового пользователя
```json
POST /auth/register
{
  "email": "user@example.com",
  "password": "string"
}
```
Ответ (201 Created):
```json
{
  "id": 1,
  "email": "user@example.com",
  "is_active": true,
  "is_superuser": false,
  "is_verified": false
}
```

### Создание нового проекта (только суперпользователь)
```json
POST /charity_project/
Тело запроса:
{
  "name": "Стерилизация бездомных кошек",
  "description": "Сбор средств на стерилизацию 30 бездомных кошек в районе",
  "full_amount": 90000
}
```
Ответ (200 OK):
```json
{
  "id": 3,
  "name": "Стерилизация бездомных кошек",
  "description": "Сбор средств на стерилизацию 30 бездомных кошек в районе",
  "full_amount": 90000,
  "invested_amount": 0,
  "fully_invested": false,
  "create_date": "2024-01-20T14:15:00",
  "close_date": null
}
```

### Создание пожертвования для котиков (только авторизованный пользователь)
```json
POST /donation/
Тело запроса:
{
  "full_amount": 10000,
  "comment": "Помощь на стерилизацию кошек"
}
```
Ответ (200 OK):
```json
{
  "id": 4,
  "full_amount": 10000,
  "comment": "Помощь на стерилизацию кошек",
  "create_date": "2024-01-20T14:30:00"
}
```

### Получение своих пожертвований (только авторизованный пользователь)
```json
GET /donation/my
```
Ответ (200 OK):
```json
[
  {

### Создание Excel-отчёта по закрытым проектам с сортировкой по скорости сбора и загрузка отчёта на Яндекс Диск (только суперпользователь)

```
